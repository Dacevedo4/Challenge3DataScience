# Challenge3DataScience

Este proyecto es la Parte 2 del Challenge Telecom X, donde nos metemos en la creación de un modelo de Machine Learning para predecir cuáles clientes podrían dejar el servicio (churn).

Partiendo del dataset que ya analizamos y limpiamos en la Parte 1, la idea es armar un pipeline que nos ayude a identificar a los clientes con más chances de irse, para que el equipo pueda tomar decisiones más inteligentes y enfocadas en retenerlos.

El enfoque mezcla preparación de datos, entrenamiento de modelos de clasificación, evaluación con métricas clave y análisis de resultados, siempre pensando en cómo impacta en el negocio.

Objetivos del proyecto:

Dejar los datos listos y bien organizados para usar en modelos de Machine Learning.

Revisar si las clases están balanceadas y ver cómo eso afecta los modelos.

Probar distintos modelos de clasificación y comparar cómo se comportan.

Medir qué tan bien funcionan usando las métricas más adecuadas para churn.

Identificar cuáles variables son las que más influyen en que un cliente se vaya.

Sacar conclusiones y dar recomendaciones prácticas basadas en los resultados


El modelo de Regresión Logística fue el que mejor se desempeñó en general, encontrando un buen equilibrio entre ser preciso y detectar a los clientes que podrían cancelar.
El análisis muestra que la fuga de clientes no se debe a un solo factor, sino a una mezcla de cosas: desde el tipo de contrato, la situación económica, hasta cómo interactúan con el servicio. Usar modelos predictivos nos ayuda a adelantarnos a estos riesgos y a tomar decisiones más inteligentes para retener clientes basándonos en datos.
